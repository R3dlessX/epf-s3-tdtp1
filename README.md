# TP Guidé GitHub (Culture Numérique 3)

Ce projet a été crée dans le cadre de l'apprentissage de Java pendant mon premier semestre de ma deuxième année à l'EPF.

## Objectifs du TP

- Créer un projet et un fichier Java dans NetBeans
- Utiliser les outils de l'éditeur (complétion, détection d'erreurs)
- Compiler et exécuter un programme
- Déboguer un programme

## Les exercices (fonctionnalités réalisées)

**Exo1 (affichage d'un message)** : afficher Bonjour, demander le prénom et le réutiliser dans le message.

**Exo2 (addition d'entiers)** : calculer la somme des n premiers entiers, trouver la boucle infinie avec le débogueur et la corriger, puis saisir n au clavier.

## Technologies utilisées

- Java
- NetBeans (projet Java with Ant)
- Git / GitHub

## Lancer un exo

Ouvrir le dossier `Exo1` ou `Exo2` dans NetBeans, puis Run (F6).
